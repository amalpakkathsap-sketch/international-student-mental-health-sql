# international-student-mental-health-sql
SQL analysis of international students' mental health scores by length of stay using PostgreSQL.
# International Students' Mental Health Analysis

## Project Overview

This project explores how the length of stay relates to mental health indicators among international students at a Japanese international university.

Using PostgreSQL, I analyzed average depression, social connectedness, and acculturative stress scores across different lengths of stay.

## Tools Used
- SQL
- PostgreSQL
- DataCamp DataLab

## SQL Concepts Practiced
- Filtering data using `WHERE`
- Grouping records using `GROUP BY`
- Counting records using `COUNT()`
- Calculating averages using `AVG()`
- Rounding values using `ROUND()`
- Sorting results using `ORDER BY`

## Research Question

Does the length of stay relate to international students' depression, social connectedness, and acculturative stress scores?

## Limitations

The analysis compares group averages and does not establish causation. Results from groups with very few students should be interpreted cautiously.
